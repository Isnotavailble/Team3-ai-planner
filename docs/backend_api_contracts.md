# Strategic Planner Backend API & Database Documentation

This document provides the complete technical specifications, database schema, and exact API contracts (request/response schemas) for the serverless backend deployed on Supabase Edge Functions.

---

## 1. System Architecture Overview

The backend is built as a lightweight, standalone, serverless application deployed to **Supabase Edge Functions** (running on **Deno**). It uses **Hono** as the router and interacts with:
1. **Supabase PostgreSQL** for persistent storage.
2. **Google Gemini 2.5 Flash** for dynamic AI insights, alerts generation, and predictive swarm simulations.

### Key Infrastructure Patterns
* **No JWT Verification (`--no-verify-jwt`)**: The endpoints are publicly accessible to allow onboarding flow guest users to query analytics and run simulations seamlessly.
* **Environment-Independent Suffix Routing**: The gateway router inside `Deno.serve` intercepts incoming requests and extracts the endpoint suffix (e.g. `/insights`), normalizing it before Hono routing. This guarantees local dev (`supabase start`) and production gateway requests behave identically.
* **Top-Level CORS Interceptor**: Preflight `OPTIONS` requests are caught at the `Deno.serve` layer, immediately returning a `200 OK` (or `204 No Content`) with the required CORS headers:
  ```json
  {
    "Access-Control-Allow-Origin": "*",
    "Access-Control-Allow-Methods": "POST, GET, OPTIONS",
    "Access-Control-Allow-Headers": "Content-Type, Authorization, x-client-info, apikey"
  }
  ```

## 2. Database Schema (PostgreSQL)

The database consists of 5 tables configured with Row Level Security (RLS).

### `profiles`
Stores the business profile configuration collected during onboarding or configuration updates.
```sql
CREATE TABLE public.profiles (
    id uuid NOT NULL DEFAULT gen_random_uuid(),
    business_name text NULL,
    owner_name text NULL,
    product_category text NULL,
    sales jsonb NULL, -- E.g. {"daily": 400, "weekly": 3000, "monthly": 12000}
    monthly_expenses numeric NULL,
    rivals jsonb NULL DEFAULT '[]'::jsonb, -- Competitor profiles
    customers jsonb NULL DEFAULT '[]'::jsonb, -- Customer list
    suppliers jsonb NULL DEFAULT '[]'::jsonb, -- Supplier list
    products jsonb NULL DEFAULT '[]'::jsonb, -- Menu/products catalog
    sales_history jsonb NULL DEFAULT '[]'::jsonb, -- Uploaded CSV/Excel history
    updated_at timestamp with time zone NOT NULL DEFAULT timezone('utc'::text, now()),
    CONSTRAINT profiles_pkey PRIMARY KEY (id)
);
```

### `entities`
Stores the canvas node entities (people, products, companies) for the strategic diagram.
```sql
CREATE TABLE public.entities (
    id text NOT NULL,
    profile_id uuid NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
    name text NOT NULL,
    type text NOT NULL, -- 'you' | 'company' | 'segment'
    x integer NOT NULL, -- Canvas coordinate
    y integer NOT NULL, -- Canvas coordinate
    summary text NULL,
    CONSTRAINT entities_pkey PRIMARY KEY (id, profile_id)
);
```

### `edges`
Stores connections between the canvas nodes.
```sql
CREATE TABLE public.edges (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    profile_id uuid NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
    a text NOT NULL, -- Entity A ID
    b text NOT NULL, -- Entity B ID
    kind text NOT NULL, -- 'active' | 'tension'
    label text NULL,
    CONSTRAINT edges_pkey PRIMARY KEY (id)
);
```

### `materials`
Stores uploaded/extracted B2B signals and documents showing up in the user's dashboard feed.
```sql
CREATE TABLE public.materials (
    id text NOT NULL,
    profile_id uuid NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
    title text NOT NULL,
    type text NOT NULL, -- 'News Leak' | 'Newsletter' | etc.
    source text NULL,
    uploaded timestamp with time zone NOT NULL DEFAULT timezone('utc'::text, now()),
    summary text NULL,
    body text NULL,
    extracted jsonb NULL DEFAULT '[]'::jsonb, -- Associated entities list
    CONSTRAINT materials_pkey PRIMARY KEY (id, profile_id)
);
```

### `simulations`
Logs the history of ran strategic simulations.
```sql
CREATE TABLE public.simulations (
    id bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    profile_id uuid NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
    competitors_ratio numeric NOT NULL,
    customers_ratio numeric NOT NULL,
    distributors_ratio numeric NOT NULL,
    verdict text NULL,
    confidence numeric NULL,
    scenarios jsonb NULL,
    dynamics jsonb NULL,
    critical_agents jsonb NULL,
    created_at timestamp with time zone NOT NULL DEFAULT timezone('utc'::text, now()),
    CONSTRAINT simulations_pkey PRIMARY KEY (id)
);
```

```json
{
  "profile": {
    "product": "Clothing Apparel",
    "sales": { "monthly": 12000 },
    "expenses": 8000,
    "targetScenario": "Competitor Price Cut"
  },
  "activeParameters": {
    "competitorsRatio": 70,
    "customersRatio": 80,
    "distributorsRatio": 60

  "language": "en"
}
```
